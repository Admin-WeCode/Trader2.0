# Trader 2.0

Trader 2.0 is a modern trading dashboard and analysis platform.

## Tech Stack
- **Frontend**: React + Vite (TypeScript)
- **UI & Theme**: Material UI (MUI v6) with Custom Dark Theme
- **Database & Backend**: Google Firebase & Cloud Firestore NoSQL DB

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and fill in your Firebase credentials:
```bash
cp .env.example .env
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
